AI Agent: ERP 업무를 돕는 방법

AI는 ERP를 대신하지 않습니다. 담당자가 하던 입력, 감시, 조회를 덜어주고, 실행은 언제나 ERP의 승인 절차를 거칩니다.

AI 어시스턴트: 신입사원의 업무 도우미

모든 화면 오른쪽에서 여는 1:1 AI입니다. 사내 채팅의 @AI도 같은 AI입니다. 모르는 용어와 절차를 설명하고, 데이터를 찾아 주고, 처리할 일은 실행 카드로 만들어 줍니다.

  • 업무 지식용어 사전과 역할별 업무 매뉴얼에서 답을 찾아 출처와 함께 설명합니다.
  • 데이터 조회재고, 수주 진행, LOT 추적, 검사 결과를 로그인한 사람의 권한 안에서 조회합니다. 숫자는 항상 DB 조회 결과로 답합니다.
  • 업무 초안배정 추천, 히트 편성안, 수주 등록 초안을 실행 카드로 보여줍니다. AI는 데이터를 직접 바꾸지 않고, 사용자가 확정하면 사용자 권한으로 ERP가 실행합니다.
  • 과거 사례 검색불합격 처리 후 등록된 과거 사례에서 비슷한 현상과 조치를 찾아 요약합니다. 품질 화면의 [비슷한 사례 찾기]로도 부릅니다.

사용자는 도구를 고르지 않습니다. 질문하면 AI가 맞는 도구를 골라 답하고, 처음 쓰는 사람에게는 역할별 추천 질문을 먼저 보여줍니다.

  1. 수주 등록과 재고 우선 예약합격한 미배정 슬래브 6매를 예약하고, 부족한 4매만 생산계획으로 넘깁니다.
    AI 어시스턴트 데이터 조회영업 담당이 사내 채팅에서 바로 가용 재고를 물어봅니다.
    @AI SS400 250×1200 슬래브 가용 몇 매야?
  2. 히트 편성부족분 4매(94.2톤)를 누적 수율로 역산해 히트 1개(250톤)를 편성합니다. 남는 슬래브는 여재가 됩니다.
    AI 어시스턴트 업무 지식처음 편성을 맡은 신입이 패널에서 묻고, 용어 사전과 매뉴얼을 근거로 설명을 듣습니다.
    히트 편성이 뭐예요?
  3. MRP로 원료 소요량 계산필요한 용선량에서 철광석, 석탄, 석회석, 합금철 소요량을 계산하고 잔량과 입고예정을 뺍니다.
    Agent 원료 부족 감지주기적으로 소요량과 잔량을 비교해, 석회석이 모자라면 구매요청 초안을 만들고 이유를 설명합니다.
  4. 구매요청 등록구매 담당이 품목, 수량, 희망 입고일을 입력해 구매요청을 올립니다.
    대화에서 구매요청 초안업무방 메시지를 읽어 초안을 채웁니다. 담당자는 확인만 하면 됩니다.
    석회석 300톤 다음 주 수요일까지 필요합니다
  5. 팀장 승인과 발주팀장이 승인하면 공급업체별로 발주가 묶여 나갑니다.
  6. 입고와 원료 LOT 생성부분 입고를 받고, 입고를 확정하면 원료 LOT이 만들어집니다.
  7. 제선, 제강, 연주 실적용선, 히트, 슬래브 LOT이 차례로 생기고 서로 연결됩니다.
    Agent 납기 위험 알림납기 대비 생산이 늦어지면 담당자에게 먼저 알립니다.
  8. 검사와 재생산검사값을 입력하면 시스템이 판정하고, 합격 슬래브는 원래 수주에 자동 예약됩니다. 모자라면 담당자가 재생산을 등록합니다.
    Agent 합격 매수 부족 감지검사 결과가 들어오는 즉시 부족 매수를 계산해 재생산 계획 초안을 만듭니다.
    과거 사례 검색품질 담당이 [비슷한 사례 찾기]를 누르면 과거 표면 불합격 사례와 당시 조치를 요약해 보여줍니다. 처리 후에는 AI가 쓴 초안으로 새 사례를 등록합니다.
  9. 출하와 밀시트오래된 재고부터 배정을 추천받아 확정하고, 출고를 확정하면 밀시트가 만들어집니다.
    AI 어시스턴트 업무 초안담당자가 요청하면 배정 추천을 실행 카드로 보여주고, [배정 확정]을 누르면 담당자 권한으로 저장됩니다.
    SO-0142 슬래브 추천해줘
    Agent 여재 장기 보유 감지오래 남아 있는 여재 슬래브를 대기 중인 수주에 배정하도록 추천합니다.
  10. 역추적과 이력 확인슬래브 번호로 원료까지 거슬러 올라가고, 이 수주의 판단 과정을 시간순으로 확인합니다.
    AI 어시스턴트 데이터 조회패널에서 LOT 번호로 물어보면 역추적 결과와 화면 링크를 줍니다.

AI 기능과 돕는 ERP 업무

AI 기능돕는 ERP 업무하는 일
대화 → ERP구매 (이후 출하·생산으로 확장)업무방 메시지에서 품목, 수량, 날짜를 뽑아 업무 초안을 만듭니다.
Factory Agent구매, 생산, 재고, 품질원료 부족, 납기 위험, 합격 매수 부족, 여재 장기 보유, 불합격률 상승을 감지해 대응 초안과 알림을 만듭니다.
회의 → 업무업무·알림, 구매회의 음성을 기록하고 요약, 결정사항, 담당자와 마감일이 있는 할 일을 뽑습니다.
AI 어시스턴트전 영역오른쪽 패널과 사내 채팅 @AI로 부르는 신입 도우미입니다. 용어·절차 설명, 데이터 조회, 업무 초안(실행 카드), 과거 사례 검색을 합니다.
과거 사례 DB품질불합격 처리 후 현상, 원인, 조치를 사례로 등록하고, 비슷한 사례를 찾아 요약합니다.

AI 사용 원칙

  • AI가 만든 결과는 모두 초안입니다. 담당자가 확인하고, 필요한 경우 ERP의 승인 절차를 거쳐야 실행됩니다.
  • AI는 조회와 초안 작성만 합니다. 업무 데이터는 직접 바꾸지 않고, 실행 카드의 확정은 사용자 권한으로 ERP가 실행합니다.
  • 숫자는 DB 조회 결과로만 답하고, 답변마다 출처를 붙입니다. 자료에 없는 내용은 확인할 수 없다고 답합니다.
  • AI가 만든 초안과 승인, 실행은 모두 작업 로그에 남습니다.
