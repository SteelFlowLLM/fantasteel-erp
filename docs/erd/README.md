# ERD

서버 스키마(`server/prisma/schema.prisma`)의 기준이다. 테이블·컬럼 이름은 여기 있는 ERD를 그대로 쓴다.

## 넣을 파일

| 파일 | 내용 |
|---|---|
| `erd.dbml` | dbdiagram에서 내보낸 DBML. 컬럼·타입·키(unique)·인덱스·관계가 모두 들어 있어 스키마를 만들 때 이 파일을 읽는다 |
| `erd.pdf` (선택) | 같은 ERD의 그림. 사람이 볼 때 쓴다 |

DBML을 내보낼 수 없으면 PDF만 넣어도 된다. 그때는 키·인덱스·관계를 따로 확인한다.

## 바꿀 때

ERD를 먼저 고치고 여기 파일을 바꾼 뒤, 스키마 담당자가 `schema.prisma`와 마이그레이션에 반영한다(코드 컨벤션 7-3).
