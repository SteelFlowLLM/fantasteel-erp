# 철강맨 — AI 어시스턴트 상황별 디자인 목록

AI 어시스턴트와 대화할 때 채팅 옆에 붙일 철강맨(24px, 눈 버전) 모션 목록입니다.
AI가 도구로 자료를 찾고, 못 찾고, 찾은 결과를 보여 주는 흐름에 맞춰 상황을 나눴습니다.

- 디자인만 만들어 둡니다. 화면 적용은 아직 하지 않습니다.
- 상황마다 시안을 2~3개(A/B/C) 만들고, 괜찮은 것을 골라 씁니다.
- 근거: AI 어시스턴트 화면 `client/src/features/shell/AiPanel.tsx`의 안내 문구, `SPEC.md` 4장 4~5번, 일반적인 도구 사용 대화 흐름. 노션 설계 문서 6종에는 이 흐름이 없습니다.

## 대화 한 번의 흐름

```
대기 → (사용자 입력 중) → 생각 중 → 도구 실행 중 → 결과 판단 → 답 쓰는 중 → 답 완료
                                   ↑ 여러 번 반복될 수 있음      ↘ 못 찾음 / 일부만 / 권한 밖 / 오류
```

## 상태 표시

| 표시 | 뜻 |
|---|---|
| 완료 | 확정해서 바로 쓸 수 있음 |
| 시안 | `steelman-pixel/assistant/`에 시안 A/B/C가 있음 (고르기 전) |
| 미착수 | 아직 그리지 않음 |

## 1. 이미 정한 상황

| 단계 | 상황 | 쓰는 때 | 시안 | 상태 |
|---|---|---|---|---|
| 대기 | 기본 대기 | 패널을 열어 두고 아무것도 안 할 때 | `motion/` 기본·깜빡 | 완료 |
| 대기 | 인사 | 패널을 열 때 | A 뿅 등장 · B 통통 + 음표 · C 손 흔들기 | 시안 |
| 생각 | 생각 중 | 질문을 보내고 답을 기다릴 때 | A 말풍선 점점점 · B 갸우뚱 두리번 · C 톱니바퀴 | 시안 |
| 도구 | 조회 중 | 데이터를 찾을 때 (출처 "조회 데이터") | A 돋보기 훑기 · B 두리번 + 로딩바 · C 돋보기 반짝 | 시안 |
| 답 | 답 완료 | 답이 다 나왔을 때 | A 끄덕끄덕 · B 체크 뿅 · C 전구 반짝 | 시안 |
| 예외 | 확인할 수 없음 | 자료에 없어 답할 근거가 없을 때 | A 두리번 + 물음표 · B 물음표 말풍선 · C 머쓱 땀방울 | 시안 |
| 예외 | 권한 밖 안내 | 내 역할 밖의 요청일 때 | A 자물쇠 뿅 · B 도리도리 · C 입에 자물쇠 | 시안 |
| 예외 | 오류 | 연결이 실패했을 때 | A 헬멧 펑 · B 빙글빙글 · C 헬멧 삐뚤 | 시안 |
| 기타 | 준비 중 | 지금처럼 기능이 준비 중(P2)일 때 | A 공사 표지판 · B 라바콘 · C 경광등 | 시안 |

## 2. 더 필요한 상황

### 꼭 필요

| 단계 | 상황 | 왜 따로 필요한지 | 디자인 아이디어 | 상태 |
|---|---|---|---|---|
| 입력 | 듣는 중 | 사용자가 질문을 입력하는 동안 반응 | A 귀 기울이기 · B 끄덕 맞장구 · C 초롱초롱 | 시안 |
| 도구 | 문서 찾는 중 | 용어 사전·업무 매뉴얼 검색은 데이터 조회와 출처 종류가 다름 | A 책 넘기기 · B 책 들고 두리번 · C 책 + 돋보기 | 시안 |
| 결과 | 찾았다! | 자료를 찾은 순간과 답을 다 쓴 순간은 다른 장면 | A 돋보기 번쩍 · B 반짝 점프 · C 쪽지 발견 | 시안 |
| 결과 | 결과 0건 | 검색은 됐는데 결과가 없음 ("확인할 수 없음"은 답할 근거가 없음) | A 빈 상자 · B X 말풍선 · C 빈 쪽지 | 시안 |
| 답 | 답 쓰는 중 | 답이 한 글자씩 나오는 동안 (생각 중과 다른 장면) | A 연필 사각사각 · B 말하며 점점점 | 시안 |
| 초안 | 초안 완성 / 확인 부탁 | "AI는 조회와 초안만, 반영은 사람이 확정" — 사용자에게 확정을 부탁하는 장면 | A 서류 내밀기 · B 꾸벅 인사 · C 여기 봐주세요(화살표) | 시안 |
| 예외 | 시간 초과 / 느림 | 도구 응답이 오래 걸릴 때 (오류는 아님) | A 모래시계 · B 흐물흐물 · C 빙글 로딩 | 시안 |

### 있으면 좋음

| 단계 | 상황 | 왜 따로 필요한지 | 디자인 아이디어 | 상태 |
|---|---|---|---|---|
| 도구 | 여러 단계 진행 | 도구를 2~3번 이어 쓸 때 같은 모션만 반복되면 멈춘 것처럼 보임 | 단계 점 ●○○ → ●●○ 이 차오름 | 미착수 |
| 결과 | 일부만 찾음 | 요청한 것 중 일부만 있을 때 | 반쯤 찬 체크와 머쓱한 표정 | 미착수 |
| 답 | 결과 보여주기 | 표나 목록을 옆에 펼쳐 보여줄 때 | 몸과 눈이 결과 쪽을 향함 | 미착수 |
| 예외 | 다시 시도 중 | 오류 뒤 자동으로 다시 할 때 | 헬멧을 고쳐 쓰고 다시 힘냄 | 미착수 |
| 예외 | 중단됨 | 사용자가 멈춤을 눌렀을 때 | 멈칫하는 정지 동작 | 미착수 |

### 나중에

| 단계 | 상황 | 쓰는 때 | 디자인 아이디어 | 상태 |
|---|---|---|---|---|
| 도구 | 계산 중 | 톤·수량 같은 숫자를 계산할 때 | 주판이나 숫자가 튐 | 미착수 |
| 답 | 출처 안내 | 답 아래 출처를 강조할 때 | 책·링크 아이콘을 내밂 | 미착수 |
| 반응 | 고마워요 | 답에 좋아요를 눌렀을 때 | 하트가 뿅 | 미착수 |
| 반응 | 아쉬워요 / 개선할게요 | 답에 싫어요를 눌렀을 때 | 꾸벅 사과하며 메모 | 미착수 |

### 합칠 수 있는 것

- "확인할 수 없음"과 "결과 0건"은 하나로 합쳐도 됩니다.
- "조회 중"과 "문서 찾는 중"은 소품(돋보기·책)만 바꿔 같이 만들 수 있습니다.

## 4. 새로 그려야 하는 소품

원본 디자인(`steelman.png`)에 없어서 새로 그리는 것들입니다.

- 이미 그린 것(시안): 말풍선, 톱니바퀴, 돋보기, 로딩바, 체크, 전구, 물음표, 느낌표, 자물쇠, 별, 연기, 공사 표지판, 라바콘, 경광등, 음표, 손, 소리 물결, 책, 빈 상자, 쪽지·서류, 연필, 화살표, 모래시계, 빙글 로딩, X 표시

- 모션용으로 더한 것: 그림자, 반짝이, 눈물, 땀방울, z

## 5. 파일 위치 (`steelman-pixel/assistant/`)

| 파일 | 내용 |
|---|---|
| `steelman_assistant.aseprite` | 시안 44개 전부. 태그 = `상황 시안`(예: `생각 중 A`). 레이어: 배경 · 그림자 · 외곽선 · 몸 · 헬멧 · 표정 · 효과 |
| `overview.png` / `overview_transparent.png` | 이름표를 붙인 한눈에 보기 (배경 있음 / 투명) |
| `gif/` · `gif_transparent/` | 시안별 GIF, 8배 확대 (`01_thinking_A.gif` …) |
| `sheet/` | 한 줄에 시안 하나씩 놓은 시트(실제 크기) + 프레임·재생 시간·태그 json |
| `icons/` | 버튼·아바타용 정지 아이콘 16 · 20 · 24px (배경 있음 / 투명, 8배 미리보기 포함) |

- 투명 버전은 Aseprite에서 `배경`·`그림자` 레이어를 끈 것과 같습니다.
- 다시 만들기: `steelman-pixel/scripts/export_assistant.sh` (Aseprite CLI, python3 + Pillow 필요)
