# 고객사 수정

API ID: API-180
Method: PATCH
Path: /api/v1/customers/:id
관련 BP: BP-MST-01
권한: MASTER_MANAGE (USE)
도메인: 기준정보
등급: P1
비고: 도출: 컨벤션 5장
설명: 고객사 정보 수정 (REQ-MST-007)
인증: AUTHENTICATED
작성 상태: 초안

동시 수정 방지(이슈 #498): 고객사 조회 응답의 `updatedAt`(ISO 8601)을 요청의 `expectedUpdatedAt`(선택)으로 돌려보내면, 그 시각 그대로일 때만 바꾸고 다르면 COM-001이다. 보내지 않으면 비교하지 않는다.
