# 생산 설정값 변경

API ID: API-188
Method: PATCH
Path: /api/v1/production-settings
관련 BP: BP-MST-01
권한: MASTER_MANAGE (USE)
도메인: 기준정보
등급: P1
비고: 도출. 단건 설정 리소스라 :id 없음
설명: 히트 용량·납기 위험 기준일 변경 (REQ-MST-009)
인증: AUTHENTICATED
작성 상태: 초안

동시 수정 방지(이슈 #498): 생산 설정값 조회 응답의 `updatedAt`(ISO 8601)을 요청의 `expectedUpdatedAt`(선택)으로 돌려보내면, 그 시각 그대로일 때만 바꾸고 다르면 COM-001이다. 보내지 않으면 비교하지 않는다.
