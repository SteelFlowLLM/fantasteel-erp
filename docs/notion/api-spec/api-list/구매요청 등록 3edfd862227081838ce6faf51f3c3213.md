# 구매요청 등록

API ID: API-143
Method: POST
Path: /api/v1/purchase-requisitions
관련 BP: BP-PUR-01
권한: PURCHASE_REQUISITION_CREATE (USE)
도메인: 구매
등급: P1
비고: 12.2절 API. 임시 저장 없음. 요청자·부서는 인증 컨텍스트에서 가져옴. 원료 수량은 톤(소수 3자리). 부서장 미지정이면 PUR-001. MRP를 다시 계산해도 같은 계획의 구매요청을 중복 생성하지 않음. 작업 로그 PURCHASE_REQUISITION_CREATED
설명: MRP 결과를 참고해 원료 품목·수량(톤)·희망 입고일·관련 계획·수주·요청 근거로 구매요청을 등록. 등록하면 바로 요청자 소속 부서장의 승인 대기(WAITING_APPROVAL) (REQ-PUR-001, REQ-PUR-002)
인증: AUTHENTICATED
작성 상태: 초안
