# 입고 취소

API ID: API-286
Method: POST
Path: /api/v1/goods-receipts/:id/cancel
관련 BP: BP-PUR-02
권한: GOODS_RECEIPT_CONFIRM (USE)
도메인: 구매
등급: P1
비고: 문서 밖 기능(2026-10-22, 이슈 #500, BP-PUR-02 반대 거래). 그 입고로 만든 원료 LOT을 쓰지 않았을 때만(투입·배정 없음, 잔량 = 처음 양, 아니면 PUR-006). 사유 필수(500자). 원래 입고는 두고 같은 발주 품목에 음수 입고 1행(reversed_goods_receipt_id = 원래 입고)을 남기고 원료 LOT은 잔량 0·RECEIPT_CANCELLED. 발주 상태는 입고 누계로 되돌림. 취소·마감된 발주면 PUR-007, 이미 취소했으면 COM-001, 취소 행은 COM-004. 작업 로그 GOODS_RECEIPT_CANCELLED
설명: 쓰지 않은 원료 LOT의 입고를 사유와 함께 반대 거래(음수 입고)로 취소한다. 취소 행을 돌려준다 (REQ-PUR-004, REQ-LOT-004)
인증: AUTHENTICATED
작성 상태: 초안
