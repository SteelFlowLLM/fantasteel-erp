## 음성 전사 규칙 (2026-10-22, 이슈 #522)

- 음성은 `POST /api/v1/meeting-minutes/audio`(multipart)로 받는다. 참석자 수를 음성 서버에 **최대 화자 수**로, 참석자 이름·강종 코드·원료·고객사·공급업체 이름과 용어 사전 공정 용어를 200자 이하 **용어 힌트**로 보낸다(저장하지 않는다)
- 긴 녹음은 음성 서버가 약 3분 조각으로 나눠 받아쓰고 진행을 `transcriptionProgress`(API-259)로 보인다. 원본 녹음은 지금처럼 저장하지 않는다
- 받아쓴 글이 없으면 `FAILED` + "말소리를 찾지 못했어요. 녹음에 목소리가 담겼는지 확인하고 다시 올려 주세요"
- 자세한 규칙은 `docs/backend/meeting-minutes.md`, 음성 서버는 `docs/backend/stt.md`
