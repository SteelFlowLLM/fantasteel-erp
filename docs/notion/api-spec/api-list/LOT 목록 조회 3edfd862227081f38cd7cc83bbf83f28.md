# LOT 목록 조회

API ID: API-235
Method: GET
Path: /api/v1/lots
관련 BP: BP-LOT-01
권한: 없음 (LOT 추적은 전 역할)
도메인: LOT·로그
등급: P1
비고: 도출: 컨벤션 5장
설명: LOT 번호·유형(원료·용선·히트·슬래브·코일)으로 검색 (REQ-LOT-001·005)
인증: AUTHENTICATED
작성 상태: 초안

쿼리: `lotNo`는 60자까지(넘으면 COM-004). `withLinks=true`(선택)면 목록 줄마다 상위 히트(`heat`: 번호와 그 히트의 검사 판정)·불합격 처리(`disposition`)·해제되지 않은 마지막 배정(`allocation`, 슬래브·코일만)·원료 종류(`rawMaterialType`)를 함께 준다. 값은 LOT 상세 조회와 같은 규칙이고, 화면이 줄마다 상세를 따로 부르지 않게 하려는 것이다(이슈 #498).
