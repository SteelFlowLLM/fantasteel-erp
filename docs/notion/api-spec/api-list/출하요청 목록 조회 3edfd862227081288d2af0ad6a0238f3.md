# 출하요청 목록 조회

API ID: API-227
Method: GET
Path: /api/v1/shipment-requests
관련 BP: BP-SHP-01
권한: SHIPMENT_REQUEST_MANAGE (VIEW) 또는 GOODS_ISSUE_CONFIRM (VIEW)
도메인: 출하·밀시트
등급: P1
비고: 도출: 컨벤션 5장. 상태는 공통코드 SHIPMENT_REQUEST_STATUS
설명: 출하요청 목록과 상태(배정 대기·배정 확정·출고 완료·취소) (REQ-SHP-001·002)
인증: AUTHENTICATED
작성 상태: 초안

쿼리: `withItems=true`(선택)면 목록 줄마다 상세(품목·배정·출고 확정자, 출하요청 상세 조회와 같은 모양)를 함께 준다. 화면이 줄마다 상세를 따로 부르지 않게 하려는 것이다(이슈 #476).
