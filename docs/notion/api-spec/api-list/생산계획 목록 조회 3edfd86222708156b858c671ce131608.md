# 생산계획 목록 조회

API ID: API-200
Method: GET
Path: /api/v1/production-plans
관련 BP: BP-PRD-01
권한: PRODUCTION_PLAN_CONFIRM (VIEW)
도메인: 생산·MRP
등급: P1
비고: 도출: 컨벤션 5장. 상태는 공통코드 PRODUCTION_PLAN_STATUS
설명: 수주 품목에 연결된 생산계획과 상태 (REQ-PRD-001)
인증: AUTHENTICATED
작성 상태: 초안

관련 조회(이슈 #498): `GET /api/v1/production-plans/hot-rolling`은 열연 투입 목록(코일 계획마다 상세와 같은 규칙의 요약 값, 권한 HOT_ROLLING_ALLOCATE VIEW), `GET /api/v1/production-plans/reproduction-checks?productionPlanIds=1,2,3`은 계획 여러 개의 연결 수주 품목과 재생산 판단(생산계획 상세의 `reproduction`과 같은 값, 권한 PRODUCTION_PLAN_CONFIRM VIEW, 100개까지)이다. 화면이 계획마다 상세를 따로 부르지 않게 하려는 것이다.
