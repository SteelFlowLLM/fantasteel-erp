# 발주 취소

API ID: API-284
Method: POST
Path: /api/v1/purchase-orders/:id/cancel
관련 BP: BP-PUR-02
권한: PURCHASE_ORDER_CONFIRM (USE)
도메인: 구매
등급: P1
비고: 문서 밖 기능(2026-10-22, 이슈 #500, BP-PUR-02 반대 거래). 입고 누계가 0인 발주(CONFIRMED)만. 사유 필수(500자, 작업 로그 사유). 발주 CANCELLED, 연결 구매요청 ORDER_CANCELLED(같은 계획·원료로 새 요청 가능, 같은 요청은 다시 발주하지 않음). 입고가 있으면 PUR-004, 이미 취소·마감이면 COM-001. 조건부 UPDATE라 입고 확정과 겹쳐도 한쪽만 반영. 작업 로그 PURCHASE_ORDER_CANCELLED
설명: 입고 전 발주를 사유와 함께 취소하고 연결 구매요청을 같은 계획·원료로 다시 요청할 수 있게 한다 (REQ-PUR-003)
인증: AUTHENTICATED
작성 상태: 초안
