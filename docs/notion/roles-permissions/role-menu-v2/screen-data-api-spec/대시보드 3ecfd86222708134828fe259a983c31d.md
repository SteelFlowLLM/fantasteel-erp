| 배치 | 위젯 위치·크기 `placements[]`(widgetCode, x, y, w, h), 기본 배치 여부 `isDefault` | 정수, 12칸 격자 / boolean | `GET /api/v1/dashboard/layout` |
| 1. 품질 즉시 조치 (KPI) | 검사 대기 `pending.count` | 정수, 건 | `QUALITY_KPI` |

| 1. 품질 즉시 조치 (KPI) | 오늘 완료율 `todayCompletion.rate` = 오늘 판정 ÷ (오늘 판정 + 지금 대기) | 비율, 판정 없으면 null | `QUALITY_KPI` |

| 1. 품질 즉시 조치 (KPI) | 미처리 불합격 `unhandledRejected.count` (처리 상태 미지정) | 정수, 건 | `QUALITY_KPI` |

| 2. 처리 필요 (큐) | 전체·검사·불합격 건수 `total`, `inspectionCount`, `dispositionCount` | 정수, 건 | `QUALITY_ACTION_QUEUE` |
| 2. 처리 필요 (큐) | LOT번호 `lotNo`, LOT 유형 `lotTypeLabel`, 단계 `stageLabel`("슬래브 검사"·"불합격") | 문자열 | `QUALITY_ACTION_QUEUE` |
| 2. 처리 필요 (큐) | 강종 `steelGradeCode` · 규격 `specCode` · 수주번호 `salesOrderNo` | 문자열, 없으면 null | `QUALITY_ACTION_QUEUE` |
| 2. 처리 필요 (큐) | 검사 마감 `dueAt`, 마감 지남·임박 `isOverdue`·`isDueSoon` | ISO 시각 / boolean | `QUALITY_ACTION_QUEUE` |
| 2. 처리 필요 (큐) | 대기 시작 `since` (검사 대기는 생산 시각, 불합격은 처리 상태 지정 또는 판정 시각) | ISO 시각 → "2시간 전" 표시 | `QUALITY_ACTION_QUEUE` |
| 2. 처리 필요 (큐) | 불합격 사유 `reason` (예: "표면 결함 수 5 개 (기준 ≤ 2 개)") | 문자열 | `QUALITY_ACTION_QUEUE` |
| 2. 처리 필요 (큐) | 처리 상태 `dispositionStatusLabel` | 공통코드 DISPOSITION_STATUS 라벨 | `QUALITY_ACTION_QUEUE` |
| 2. 처리 필요 (큐) | 담당자 `assigneeName` | 문자열, 없으면 "미배정" | `QUALITY_ACTION_QUEUE` |
| 2. 처리 필요 (큐) | 다음 조치 `nextAction`, 이동 경로 `linkPath` | 문자열 / 화면 경로 | `QUALITY_ACTION_QUEUE` |
| 3. 불합격 처리 상태 | 불합격 전체·처리 필요 수 `totalCount`, `openCount` | 정수, 개 | `DISPOSITION_SUMMARY` |
| 3. 불합격 처리 상태 | 상태별(미지정·출하 보류·격리·재작업·조건부 합격·격하·폐기) 건수 `count` · 톤 `ton` | 정수, 개 / 톤 | `DISPOSITION_SUMMARY` |
| 3. 불합격 처리 상태 | 평균·최대 체류일 `avgDwellDays`, `maxDwellDays` | 문자열 소수 1자리 / 정수, 일 | `DISPOSITION_SUMMARY` |
| 3. 불합격 처리 상태 | 오래 머문 LOT 5개 `oldestOpen[]` (lotNo, 상태, `dwellDays`) | 문자열 / 정수, 일 | `DISPOSITION_SUMMARY` |
| 4. 품질 상태 재고 | 슬래브·코일별 합격(출하 가능) `passed.qty`·`passed.ton` | 정수, 매·개 / 톤 | `QUALITY_STOCK` |
| 4. 품질 상태 재고 | 판정 대기(출하 불가) `pending.qty`·`pending.ton` | 정수, 매·개 / 톤 | `QUALITY_STOCK` |
| 4. 품질 상태 재고 | 불합격(출하 불가) `rejected.qty`·`rejected.ton`, 처리 상태별 매수 `rejectedByDisposition[]` | 정수, 매·개 / 톤 | `QUALITY_STOCK` |
| 4. 품질 상태 재고 | 합계 톤 `totals.passedTon`·`pendingTon`·`rejectedTon` | 톤 | `QUALITY_STOCK` |
| 5. 품질 성과 지표 | 공정별(성분·슬래브·코일 검사) 합격률 `passRate` · 불합격률 `rejectRate` (최근 7일) | 비율 | `QUALITY_PERFORMANCE` |
| 5. 품질 성과 지표 | 판정 수·불합격 수 `inspectedCount`, `failedCount` | 정수, 건 | `QUALITY_PERFORMANCE` |
| 5. 품질 성과 지표 | 전주 합격률 `prevPassRate` · 전주 대비 `passRateDelta` | 비율 / 비율 차 → %p 표시 | `QUALITY_PERFORMANCE` |
| 5. 품질 성과 지표 | 주요 결함 상위 3 `topDefects[]` (항목명, 검사, `count`, 전주 `prevCount`) | 문자열 / 정수, 건 | `QUALITY_PERFORMANCE` |
| 6. 품질 이슈 납기 위험 | 수주번호 `salesOrderNo` · 품목 줄 `lineNo` · 고객사 `customerName` · 규격 `specCode` | 문자열 / 정수 | `QUALITY_DELIVERY_RISK` |
| 6. 품질 이슈 납기 위험 | 납기 `dueDate`, 남은 일수 `daysToDue`, 납기 위험 `isDeliveryRisk` | 날짜 / 정수, 일(D-n) / boolean | `QUALITY_DELIVERY_RISK` |
| 6. 품질 이슈 납기 위험 | 남은 매수 `remainingQty` | 정수, 매·개 | `QUALITY_DELIVERY_RISK` |
| 6. 품질 이슈 납기 위험 | 불합격 LOT 수 `rejectedLotCount` · 미지정 `unhandledLotCount` · 출하 보류 `shipmentHoldLotCount` | 정수, 개 | `QUALITY_DELIVERY_RISK` |
| 6. 품질 이슈 납기 위험 | 재생산 계획 `reproductionPlan.productionPlanNo` | 문자열, 없으면 "없음" | `QUALITY_DELIVERY_RISK` |
| 참고 (아래쪽) | 최근 작업 로그 10건 · 공정 흐름 단계별 건수 | 기존 위젯 | `RECENT_EVENTS`, `PROCESS_FLOW` |
- 위 표는 품질 역할의 기본 배치 기준이다. 출처 API의 위젯 코드는 모두 `GET /api/v1/dashboard/widgets/:widgetCode`로 부른다. 모든 위젯 응답에는 `generatedAt`(집계 시각, ISO)과 `available`이 함께 온다.
- 표기: 톤은 문자열 소수 3자리(예: "16.250"), 비율은 0~1 문자열 소수 4자리(예: "0.7308" = 73%), 시각은 ISO 문자열이며 화면에는 한국 시간으로 표시한다. 재고·처리 상태의 톤은 슬래브·코일 규격 이론중량의 합이고 히트는 0으로 센다.
- 위젯 데이터는 로그인한 사원이면 누구나 볼 수 있다.
