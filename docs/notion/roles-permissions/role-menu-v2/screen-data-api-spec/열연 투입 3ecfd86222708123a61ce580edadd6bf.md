－ 열연 투입은 코일 계획에 필요한 매수만큼 합격 슬래브를 골라(FIFO 추천 → 확정) 열연에 넣고, 슬래브 1매당 코일 1개를 만드는 화면입니다. 남은 합격 슬래브는 여재로 남습니다.

## 1. 목적·사용 역할·필요 권한

- 필요 매수의 슬래브만 열연에 투입하고, 나머지 합격 슬래브는 미배정 여재로 남긴다 (REQ-PRD-004).
- 강종·규격이 맞는 합격 LOT을 FIFO(생산완료일)로 추천받고 담당자가 확정한다 (REQ-INV-006).

| 역할 | 권한 `HOT_ROLLING_ALLOCATE` | 쓰는 방식 |
| --- | --- | --- |
| 생산 | 사용(USE) | 추천·배정 확정·변경·투입 |
| 관리자 | 조회(VIEW) | 확인만 |

## 2. 철강 흐름에서의 위치

- 받는 것: 코일 계획·수주 품목, 코일 ↔ 슬래브 1:1 규격 매핑, 검사 합격 슬래브 (검사 입력의 "열연 투입 슬래브 배정 가능" 알림)
- 넘기는 것: 코일 LOT → 검사 입력(치수·기계적 성질) → 합격 시 원래 수주에 자동 예약 / 남은 슬래브 여재 → 재고·출하요청

## 3. 화면에 표시할 데이터

| 영역 | 필드 | 타입·단위 | 출처 API |
| --- | --- | --- | --- |
| 대상 계획 | 계획번호, 수주번호·코일 규격, 대응 슬래브 규격, 필요 매수·배정 매수 | 문자열 / 정수, 매 | `GET /api/v1/production-plans/:id` 🟡 |
| FIFO 추천 | 순위, 슬래브 LOT번호, 강종·규격, 히트 판정, 생산완료일, 야드 | 문자열 / 코드 INSPECTION_RESULT / 날짜 | `POST /api/v1/allocations/recommend` |
| 배정 현황 | 배정 LOT, 배정 상태, 배정 목적 = HOT_ROLLING(열연 투입) | 코드 ALLOCATION_STATUS · ALLOCATION_PURPOSE | `GET /api/v1/allocations?productionPlanId=` 🟡 |
| 결과 | 생성 코일 LOT `C + 슬래브번호(HT- 제외)` 예: CBOF1-260929-015-03, 남은 여재 매수 | 문자열 / 정수, 매 | `POST /api/v1/production-results` 응답 |
- 추천 조건: 히트 성분 + 슬래브 검사 합격, 미소진, 다른 수주 예약을 침범하지 않음. 동률이면 LOT 번호순 (BP-INV-01, 16장).

## 4. 사용자 동작 → API

| 동작 | 메서드·경로 | 요청 | 응답 | 권한·에러 |
| --- | --- | --- | --- | --- |
| FIFO 추천 | `POST /api/v1/allocations/recommend` | 계획·필요 매수, 목적 HOT_ROLLING | 추천 LOT 목록 (저장 안 함, 작업 로그만) | USE |
| 배정 확정 | `POST /api/v1/allocations` | 대상, lotIds | CONFIRMED 배정 | USE. INV-001 매수 부족, INV-002 미합격, INV-003 이미 배정, INV-004 이미 투입·출고 |
| 배정 해제 | `POST /api/v1/allocations/:id/release` | 배정 ID | RELEASED | USE. CONSUMED는 불가 |
| 배정 변경 (투입 전) | `POST /api/v1/allocations/:id/change` 🟡 (출하요청 페이지와 같은 제안) | 새 LOT | 기존 RELEASED + 새 CONFIRMED (한 트랜잭션) | USE |
| 열연 투입 (코일 실적) | `POST /api/v1/production-results` | 공정 HOT_ROLLING, 배정된 슬래브 | 슬래브 1매당 코일 1개 | PRODUCTION_RESULT_CONFIRM USE |

## 5. 상태 변화·작업 로그

- 배정: CONFIRMED → CONSUMED(투입) / RELEASED(변경·취소). CONSUMED는 바꿀 수 없다.
- 슬래브 LOT: AVAILABLE → CONSUMED. 코일 LOT 새로 생성(AVAILABLE), 슬래브 → 코일 1:1 연결(ACTUAL_INPUT).
- 같은 슬래브를 출하와 열연에 동시에 배정하지 않는다.
- 작업 로그: ALLOCATION_RECOMMENDED, ALLOCATION_CONFIRMED, ALLOCATION_CHANGED, ALLOCATION_RELEASED, PRODUCTION_RESULT_REGISTERED

## 6. 연결 화면·확인 필요

- 연결: 생산계획, 공정 실적, 검사 입력, 재고(여재), LOT 추적, 작업 로그
- 확인 필요
    1. 🟡 API(배정 조회·변경, 계획 상세)를 API 명세서에 추가
    2. 열연 실적을 이 화면에서 바로 등록할지, 공정 실적 화면에서 할지
    3. 열연 시작 후 수주 취소 처리 (16장: 미열연은 슬래브 여재, 열연 후 코일은 별도 결정)
