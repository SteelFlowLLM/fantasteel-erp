# 1. 영업

데모 계정: **김영업** (`2104012`) · 시작 화면: 영업 대시보드

## 하는 일

- 고객 주문을 **수주**로 등록합니다.
- 주문이 얼마나 채워졌는지(충족 현황) 지켜봅니다.
- 제품이 준비되면 **출하요청**을 하고 어떤 LOT을 보낼지 **배정을 확정**합니다.
- 출고 자체는 물류가 합니다.

## 쓰는 메뉴

- 대시보드 / 수주 목록 / 수주 등록 / 충족 현황 / 출하요청
- 볼 수만 있는 것: 생산계획, 출고, 기준정보 · 밀시트는 조회·출력 가능

## 따라 하기

### A. 수주 등록

1. 대시보드나 수주 목록의 **수주 등록** 버튼을 누릅니다.
2. 고객, 납기, 품목, 수량을 입력합니다. 수량은 **1 이상의 정수(매)**입니다. 품목은 여러 줄 넣을 수 있습니다.
3. 등록하면 시스템이 바로 다음을 합니다.
    - 남는 재고가 있으면 그만큼 **재고 예약**
    - 모자란 만큼은 **생산 필요**로 생산팀에 넘기고 알림 발송
    - 이 수주 전용 **업무방**(메신저 대화방)을 자동 생성
4. **수주 상세 보기**로 넘어가 예약 매수와 생산 필요 매수를 확인합니다.

### B. 진행 상황 보기

1. **충족 현황**에서 수주를 고릅니다.
2. 품목별로 예약 / 생산 중 / 검사 합격 매수와 납기 위험 여부를 봅니다.
3. 제품이 검사에 합격하면 "검사 합격 1매 · 출하요청 가능" 알림이 옵니다.

### C. 출하요청과 배정

1. **출하요청** 메뉴에서 보낼 수주 품목과 매수를 고르고 희망일을 넣습니다.
2. **출하요청 등록 · 배정 추천**을 누릅니다.
3. 배정 화면에 시스템이 오래된 순(FIFO)으로 추천한 LOT이 나옵니다. 바꾸고 싶으면 "~로 바꾸기"로 다른 후보와 교체합니다.
4. 배정을 확정하면 상태가 "배정 확정 · 출고 대기"가 되고 물류에 알림이 갑니다. **물류 출고 요청 보내기**로 출고 화면을 확인할 수 있습니다.
5. 물류가 출고를 확정하면 "출고 완료 · 밀시트 발행" 알림이 옵니다.

### D. 수주 수정·취소

- 등록 후 바꿀 수 있는 것은 납기, 비고, 담당자입니다. **수량은 바꿀 수 없습니다.**
- 취소하면 예약이 풀리고, 이미 만든 LOT은 여재(남는 재고)가 됩니다.

## 자주 생기는 문제

- **"수량은 1 이상의 정수(매)로 입력해 주세요"**: 소수나 0을 넣었습니다. 톤이 아니라 매수로 넣습니다.
- **"품목 기준정보가 없어요"**: 관리자가 그 품목을 "사용 안 함"으로 했거나 등록하지 않았습니다. 관리자에게 요청합니다.
- **"최대 N매까지 출하요청할 수 있어요 (예약 + 검사합격)"**: 아직 검사에 합격한 제품이 부족합니다. 충족 현황에서 생산·검사 진행을 기다립니다.
- **"예약 매수가 부족해요" / "배정할 수 없는 LOT이에요"**: 고른 LOT이 합격·같은 규격·미배정 조건을 만족하지 않습니다. 추천 목록 안에서 다시 고릅니다.
- **"이미 출하된 매수가 있어 취소할 수 없어요"**: 일부라도 출고된 수주는 취소가 안 됩니다.
- **"진행 중인 출하요청(DR-…)을 먼저 취소해 주세요"**: 출하요청을 먼저 취소한 뒤 수주를 취소합니다.
- **불합격 알림을 받았다**: 내 수주에 연결된 LOT이 불합격되면 시스템이 재생산을 자동 요청합니다. 납기가 걱정되면 업무방에서 생산팀과 상의합니다.
- **내가 안 했는데 출하요청이 생겼다**: 자동 조업이 켜져 있습니다. 시작하기 페이지를 봅니다.
