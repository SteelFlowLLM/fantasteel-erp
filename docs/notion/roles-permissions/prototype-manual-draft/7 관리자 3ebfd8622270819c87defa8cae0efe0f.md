# 7. 관리자

데모 계정: **이관리** (`1704010`) · 시작 화면: 관리자 대시보드

## 하는 일

- **사용자**를 등록하고 역할·상태를 관리하며 잠긴 계정을 풉니다.
- **역할별 권한**을 조정합니다.
- **기준정보**(품목, 원료, 생산 설정값)를 관리합니다.
- 업무 화면은 대부분 조회만 됩니다. 승인 권한은 없습니다.

## 쓰는 메뉴

- 대시보드 / 사용자 / 부서·권한 / 기준정보

## 따라 하기

### A. 사용자 관리

1. **사용자** 메뉴에서 **사용자 등록**을 누릅니다.
2. 사번(**숫자 7자리**), 이름, 부서, 역할을 입력합니다. 역할은 영업·구매·생산·품질·물류·팀장·관리자 중 하나이고, 한 사람은 한 역할만 가집니다.
3. 새 계정도 비밀번호는 `heatline`입니다.
4. 기존 사용자는 역할·부서·상태(활성/비활성)를 바꿀 수 있습니다.
5. 잠긴 계정(로그인 5회 실패)은 **잠금 해제**를 누릅니다. 연습용으로 남물류가 잠겨 있습니다.

### B. 권한 조정

1. **부서·권한**에서 역할 × 기능 표를 봅니다.
2. 칸마다 세 단계 중 하나를 고릅니다.
    - 사용: 등록·변경까지 가능
    - 조회: 보기만 가능
    - 없음: 메뉴에 들어가면 "권한 없음"
3. 저장하면 **그 역할의 모든 사용자에게 즉시 적용**됩니다. 변경 내용은 작업 로그에 남습니다.
4. 기능은 20개입니다: 수주 등록, 수주 취소, 출하요청·배정 확정, MRP 조회, 구매요청 등록, 구매요청 승인, 발주, 입고 확정, 생산계획, 공정 실적, 열연 투입 배정, 검사 입력, 불합격 상태 변경, 출고 확정, 밀시트 조회·출력, Agent 후보 승인, 사용자 관리, 기준정보, ERP Assistant 조회 범위, Message→ERP 초안 생성.

### C. 기준정보

1. **기준정보**에서 탭을 고릅니다.
2. **품목**: **품목 등록**으로 추가합니다. 코드는 `SL-강종-두께x폭`(슬래브) 또는 `CL-강종-두께x폭`(코일) 형식이고 강종은 SS400, SM490, SPHC입니다. 쓰지 않을 품목은 "사용 안 함"으로 바꿉니다.
3. **원료**: 최소 주문 단위(MOQ), 원단위, 공급업체를 고칩니다.
4. **생산 설정값**: 수율, 공정 소요 시간 등을 고칩니다. 이후 시뮬레이션과 MRP 계산에 바로 영향을 줍니다.

## 자주 생기는 문제

- **"사번은 숫자 7자리예요" / "이미 있는 사번이에요"**: 사번을 고칩니다.
- **"자기 계정은 비활성화할 수 없어요"**: 관리자 본인 계정은 끌 수 없습니다.
- **"품목코드 형식: SL-강종-두께x폭 / CL-강종-두께x폭"**: 형식과 강종(SS400, SM490, SPHC)을 확인합니다.
- **부서를 추가하고 싶다**: 이 프로토타입에서는 부서 추가가 안 됩니다.
- **권한을 바꿨더니 누군가 일을 못 한다**: 부서·권한에서 되돌립니다. 많이 꼬였으면 초기화로 기본 권한표로 돌아갑니다.
- **관리자 권한을 "없음"으로 바꿔 버렸다**: 사용자 관리 권한을 관리자에게서 빼면 화면으로는 복구할 수 없습니다. 초기화해야 합니다. 이 칸은 건드리지 않습니다.
- **품목을 "사용 안 함"으로 했더니 수주 등록이 안 된다**: 의도된 동작입니다. 다시 사용으로 바꿉니다.
