# 3. 생산

데모 계정: **박생산** (`1803021`), 최생산 (`2006011`) · 시작 화면: 생산 대시보드

## 하는 일

- 수주에서 넘어온 "생산 필요" 매수를 **히트로 편성**합니다.
- 공정(제강 → 연주) **실적**을 기록합니다.
- 코일 주문이면 슬래브를 **열연에 투입 배정**합니다.
- 원료가 모자라면 구매요청을 올릴 수 있습니다.

## 쓰는 메뉴

- 대시보드 / 생산계획 / 공정 실적 / 열연 투입 배정
- 볼 수만 있는 것: MRP, 검사, 기준정보

## 공정 흐름

고로 출선(용선) → 제강(전로 BOF1·BOF2) → 연주(슬래브 LOT 생성) → 검사 → [코일 주문이면] 열연 압연(코일 LOT 생성) → 검사

검사 자체는 품질 담당이 합니다.

## 따라 하기

### A. 생산 필요 처리 (생산계획)

1. "생산 필요 N매 이관" 알림이 오면 **생산계획**을 엽니다.
2. 품목마다 세 가지 중에서 고릅니다.
    - **재고로 충당**: 남는 재고가 있으면 생산하지 않고 재고를 예약합니다.
    - **히트 편성**: 슬래브 규격을 고르고 수주별 매수를 나눠 담습니다. 한 히트에서 나오는 매수(히트 용량)를 넘길 수 없고, 남는 자리는 여재로 생산됩니다.
    - **열연 투입 배정**: 코일 주문이고 쓸 수 있는 합격 슬래브가 이미 있을 때 씁니다.
3. 편성한 히트는 **목록 / 일정** 보기로 확인합니다. 시작 시각은 전로가 비는 시간으로 자동 잡힙니다.
4. 아직 시작 전(계획 상태)인 히트만 취소하거나 일정을 바꿀 수 있습니다.

### B. 공정 실적

1. **공정 실적**에서 히트를 고릅니다.
2. **실적 저장**을 누르면 현재 공정이 지금 시각으로 완료 처리되고 다음 단계로 넘어갑니다. (계획 → 제강 시작 → 출강·연주 시작 → 연주 완료)
3. 연주가 끝나면 슬래브 LOT이 생기고 품질팀에 검사 대기 알림이 갑니다.
4. 누르지 않아도 시간이 되면 시뮬레이터가 알아서 진행합니다. 실적 저장은 "시뮬레이터보다 먼저 지금 끝내기"입니다.

### C. 열연 투입 배정

1. **열연 투입 배정**에서 코일 수주 품목을 고릅니다.
2. 추천된 합격 슬래브 중에서 투입할 것을 고르고 **배정 확정**을 누릅니다.
3. 압연 대기 중인 배정은 **해제**하거나 다른 슬래브로 바꿀 수 있습니다.
4. 코일 수주용으로 편성해 만든 슬래브는 검사에 합격하면 자동으로 열연 대기열에 들어갑니다. 이 화면은 주로 여재 슬래브를 끌어다 쓸 때 필요합니다.

### D. 원료가 모자랄 때

- 구매요청을 직접 올릴 수 있습니다. 메신저에 "FeMn 20톤 다음 주까지 필요"처럼 쓴 뒤 그 메시지에서 **구매요청 초안 만들기**를 눌러도 됩니다. (8. 공통 기능 참고)

## 자주 생기는 문제

- **"히트 용량(N매)을 넘었어요"**: 담은 매수를 줄이거나 히트를 하나 더 편성합니다.
- **"SO-… 품목N은(는) ○○ 소재가 필요해요"**: 고른 슬래브 규격이 그 주문과 맞지 않습니다. 안내된 규격으로 바꿉니다.
- **"품목N의 계획 전 매수는 N매예요"**: 이미 다른 히트에 편성됐거나 재고로 충당된 만큼은 다시 담을 수 없습니다.
- **"BOF1에서 HT-… 제강이 진행 중이에요"**: 같은 전로에 앞 히트가 돌고 있습니다. 끝나길 기다리거나 앞 히트의 실적을 먼저 저장합니다.
- **"이미 시작된 히트는 일정을 바꿀 수 없어요" / "계획 상태의 히트만 취소할 수 있어요"**: 제강이 시작된 뒤에는 되돌릴 수 없습니다.
- **"○○ 가용 재고가 없어요"**: 재고 충당이 안 됩니다. 히트를 편성합니다.
- **"배정할 수 없는 LOT이에요 (합격·동일 규격·미배정만 가능)"**: 검사 전이거나 불합격이거나 이미 다른 곳에 배정된 슬래브입니다.
- **"예약된 재고를 제외하면 가용 슬래브가 부족해요"**: 다른 수주가 예약한 슬래브라 쓸 수 없습니다.
- **불합격 알림 "재생산 1매 요청"**: 불합격된 LOT의 배정은 자동으로 풀립니다. 생산계획에 생산 필요 1매가 다시 생기니 A 절차대로 처리합니다.
- **제강 시작 로그에 "○○ N t 부족"**: 합금철 재고가 모자란 채로 시작됐다는 표시입니다. 구매팀에 알리거나 구매요청을 올립니다.
- **내가 안 했는데 히트가 편성됐다**: 자동 조업이 켜져 있습니다. 작업 로그에 "자동 조업"으로 남습니다.
