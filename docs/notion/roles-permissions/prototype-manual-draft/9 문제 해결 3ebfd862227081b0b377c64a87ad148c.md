# 9. 문제 해결

역할과 상관없이 생기는 문제를 증상별로 모았습니다. 역할별 업무 오류는 각 역할 페이지 아래쪽에 있습니다.

## 접속·실행

- **페이지가 안 열린다**: `app` 폴더에서 `npm run dev`가 실행 중인지 확인합니다. 주소는 `http://localhost:5173`입니다.
- **"서버에 다시 연결하는 중… (npm run dev 실행 확인)"** 또는 제어 막대의 점이 빨강: 서버가 꺼졌거나 연결이 끊겼습니다. 터미널에서 서버를 다시 켭니다. 켜지면 자동으로 다시 연결됩니다.
- **`npm install`이나 실행에서 오류**: Node.js 버전이 22.18 이상인지 확인합니다.
- **다른 PC에서 접속이 안 된다**: 같은 와이파이인지, 주소를 실행한 컴퓨터의 IP로 넣었는지 확인합니다.

## 로그인

- **"사번 또는 비밀번호가 맞지 않아요 (N/5)"**: 비밀번호는 `heatline`입니다. 데모 계정 버튼을 쓰면 비밀번호가 필요 없습니다.
- **"로그인 5회 실패로 잠긴 계정이에요"**: 관리자(이관리)로 들어가 사용자 메뉴에서 잠금 해제합니다.
- **"비활성 계정이에요"**: 관리자가 상태를 활성으로 바꿔야 합니다.
- **"알 수 없는 사용자예요. 다시 로그인해 주세요"**: 초기화 등으로 계정이 사라졌습니다. 다시 로그인합니다.

## 권한

- **"권한 없음" 화면**: 내 역할에 없는 기능입니다. 다른 역할 계정으로 전환하거나 관리자에게 권한을 요청합니다.
- **버튼이 회색이고 자물쇠 표시**: 조회 권한만 있는 상태입니다.
- **"비활성·잠김 계정은 작업할 수 없어요"**: 로그인한 뒤에 계정이 비활성·잠김으로 바뀌었습니다. 관리자에게 요청합니다.

## 화면이 이상할 때

- **"화면을 표시하지 못했어요"**: **다시 시도**를 누릅니다. 계속되면 새로고침합니다.
- **화면이 안 바뀐다 / 다른 창과 다르게 보인다**: 제어 막대의 점이 초록인지 확인하고 새로고침합니다.
- **버튼을 눌렀는데 빨간 안내가 뜬다**: 문구가 곧 원인입니다. 역할 페이지의 "자주 생기는 문제"에서 같은 문구를 찾습니다.

## 시간·시뮬레이션

- **시계가 멈춰 있다**: 제어 막대가 일시정지(▶ 표시)인지 확인합니다. 브라우저 창이 하나도 없으면 시계가 멈추는데, 다시 열면 이어집니다.
- **너무 빨리 지나간다 / 너무 느리다**: 배속을 바꿉니다. 직접 조작을 연습할 때는 1×나 일시정지가 편합니다.
- **내가 안 한 일이 되어 있다**: 두 가지 중 하나입니다. (1) 자동 조업이 켜져 있다. (2) 제강·연주·압연·검사 자동 판정처럼 원래 시스템이 진행하는 일이다. **작업 로그**에서 누가 했는지 확인합니다.
- **기다려도 생산이 진행되지 않는다**: 계획된 히트가 있는지(생산계획), 시계가 돌고 있는지 확인합니다. 자동 조업이 꺼져 있으면 히트 편성은 사람이 해야 합니다.
- **승인 대기에서 멈춰 있다**: 팀장 승인은 자동으로 되지 않습니다. 강팀장으로 로그인해 승인합니다.

## AI

- **제어 막대에 "AI 규칙 기반" 또는 "꺼짐"**: 외부 AI에 연결되지 않은 상태입니다. 미리 정해 둔 규칙 기반 답변으로 동작하므로 그대로 써도 됩니다.
- **AI를 연결하고 싶다**: 제어 막대의 **AI**를 눌러 주소(LM Studio 기본 `http://127.0.0.1:1234/v1`), 모델, API 키를 넣고 **저장** 후 **연결 테스트**를 누릅니다.
- **AI가 "거절"한다**: 등록·변경 요청이거나 내 권한 밖의 데이터를 물었습니다. AI는 조회와 초안만 합니다.
- **"이 메시지에서 원료·수량을 찾지 못했어요"**: 메시지에 원료 이름과 수량이 분명하지 않습니다. 구매요청 화면에서 직접 등록합니다.
- **"이 메시지로 만든 초안(PR-…)이 이미 있어요"**: 같은 메시지로는 한 번만 만들 수 있습니다. 기존 초안을 엽니다.
- **"이 브라우저는 음성 인식을 지원하지 않아요"**: Chrome·Edge를 쓰거나 데모 대본·텍스트 붙여넣기를 씁니다.

## 되돌리고 싶을 때

- 출고 확정, 검사 판정, 발주 확정처럼 **확정 단계는 되돌리는 기능이 없습니다.**
- 연습하다 데이터가 꼬이면 제어 막대의 **초기화**로 2026-10-02 09:10 상태로 돌아갑니다.

<aside>
⚠️

초기화는 **모든 창, 모든 사람의 데이터**를 한꺼번에 되돌립니다. 같이 쓰는 중이면 먼저 알립니다.

</aside>

## 그래도 안 되면

1. 화면에 뜬 문구를 그대로 적습니다.
2. 어느 역할로, 어느 화면에서, 무엇을 눌렀는지 적습니다.
3. 작업 로그에서 직전 기록을 확인합니다.
4. 팀 메신저나 대시보드의 이슈 목록에 올립니다.
