# 2. 구매

데모 계정: **서구매** (`1907015`) · 시작 화면: 구매 대시보드

## 하는 일

- MRP 결과로 **부족한 원료**를 확인합니다.
- **구매요청**을 올리고, 팀장 승인이 나면 **발주**합니다.
- 원료가 도착하면 **입고 확정**을 합니다.

## 쓰는 메뉴

- 대시보드 / MRP 결과 / 구매요청 / 발주 / 입고
- 볼 수만 있는 것: 생산계획, 기준정보

## 원료와 공급업체 (초기 데이터)

- 철광석 · 서해광업 · 1,000 t 단위
- 코크스 · 동진코크 · 100 t 단위
- 석회석 · 태백석회 · 50 t 단위
- FeMn · 대한합금철 · 5 t 단위
- FeSi · 대한합금철 · 1 t 단위
- Al 탈산제 · 한빛메탈 · 1 t 단위

"단위"는 최소 주문 단위(MOQ)입니다. 요청 수량은 이 단위의 배수여야 합니다.

## 구매요청의 상태

초안 → 승인 대기 → 승인 → 발주 완료. 중간에 반려 또는 폐기가 될 수 있습니다.

## 따라 하기

### A. 부족 원료 확인

1. **MRP 결과**를 엽니다. 매일 08:00(공장 시각)에 자동 계산됩니다.
2. **부족만**을 눌러 부족한 원료만 봅니다.
3. 부족 행의 초안 버튼을 누르면 MOQ에 맞춘 수량으로 구매요청 초안이 만들어집니다.
4. 승인 전 구매요청은 입고 예정에 잡히지 않습니다. 발주까지 가야 다음 MRP부터 반영됩니다.

### B. 구매요청 올리기

1. **구매요청** 메뉴에서 **구매요청 등록**을 누르면 초안이 생기고 상세 화면이 열립니다.
2. 원료, 수량, 희망 입고일을 확인·수정합니다.
3. **확정 → 팀장 승인 요청**을 누릅니다. 팀장에게 알림이 갑니다.
4. 메신저나 회의록에서 AI가 만든 초안도 같은 화면에서 확인하고 확정합니다. **초안은 요청자 본인만 수정·확정할 수 있습니다.**
5. 반려되면 사유를 보고 수정한 뒤 다시 확정하거나 폐기합니다.

### C. 발주

1. "승인됨 · 발주 가능" 알림이 오면 **발주** 메뉴를 엽니다.
2. 승인된 구매요청을 고릅니다. **같은 원료끼리만** 한 발주로 묶을 수 있습니다.
3. **발주 확정**을 누릅니다. 구매요청 상태가 "발주 완료"로 바뀝니다.

### D. 입고

1. **입고** 메뉴에서 발주를 고릅니다.
2. 입고 수량을 넣고 **입고 확정**을 누릅니다.
3. 원료 LOT이 생기고, 발주는 "부분 입고" 또는 "입고 완료"가 됩니다. 나눠서 여러 번 입고할 수 있습니다.

## 자주 생기는 문제

- **"○○은(는) N t 단위로 요청해 주세요 (MOQ)"**: 수량을 최소 주문 단위의 배수로 고칩니다.
- **"희망 입고일을 입력해 주세요" / "수량을 입력해 주세요"**: 빈 칸을 채웁니다.
- **"요청자(○○○)만 확정할 수 있어요" / "초안은 요청자만 수정할 수 있어요"**: 다른 사람 이름으로 만들어진 초안입니다. 그 사람에게 확정을 부탁합니다.
- **"확정된 요청은 수정할 수 없어요"**: 이미 승인 대기 이후 단계입니다. 팀장에게 반려를 요청한 뒤 고칩니다.
- **"PR-…은(는) 팀장 승인(APPROVED) 후 발주할 수 있어요"**: 아직 승인 전입니다. 팀장(강팀장)에게 승인을 요청합니다.
- **"같은 원료의 요청만 한 발주로 묶을 수 있어요"**: 원료별로 나눠 발주합니다.
- **"발주 잔량(N t)보다 많이 입고할 수 없어요"**: 입고 수량을 잔량 이하로 줄입니다.
- **내가 안 했는데 발주·입고가 됐다**: 자동 조업이 켜져 있습니다. 승인된 요청을 4시간 안에 발주하지 않으면 시스템이 발주하고, 납기일이 지난 발주는 시스템이 입고 처리합니다.
