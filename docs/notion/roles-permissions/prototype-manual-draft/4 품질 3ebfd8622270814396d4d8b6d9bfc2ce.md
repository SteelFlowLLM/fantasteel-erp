# 4. 품질

데모 계정: **정품질** (`1911030`), 한품질 (`2107019`) · 시작 화면: 품질 대시보드

## 하는 일

- 슬래브·코일 LOT의 **검사 측정값을 입력**하고 합격/불합격을 판정합니다.
- **불합격 LOT**을 보류·격하·폐기로 처리합니다.
- LOT 추적으로 원인을 거슬러 봅니다.

## 쓰는 메뉴

- 대시보드 / 검사 입력 / 불합격 관리 / LOT 추적
- 볼 수만 있는 것: 생산계획, 공정 실적, 출고, 기준정보 · 밀시트는 조회·출력 가능

## 검사 항목과 판정 규칙

- 슬래브: 두께, 폭, 길이, 표면 결함
- 코일: 인장강도, 항복강도, 연신율(강종에 따라), 두께, 폭, 표면 결함
- 수치 항목은 기준 범위 안이면 합격입니다. 범위는 화면에 표시됩니다.
- 표면 결함은 **"없음"(또는 "양호")**이어야 합격입니다.
- 한 항목이라도 벗어나면 그 LOT은 불합격입니다. 합격/불합격은 입력값으로 **자동 판정**되며 사람이 직접 고르지 않습니다.

## 따라 하기

### A. 검사 입력

1. "검사 대기 슬래브 N매" 알림이 오면 **검사 입력**을 엽니다.
2. 검사 대기 LOT을 고릅니다.
3. 모든 항목의 측정값을 넣습니다. 도중에 멈추려면 **임시 저장**을 누릅니다.
4. **판정 저장**을 누르면 합격/불합격이 확정됩니다. 확정 뒤에는 고칠 수 없습니다.

<aside>
⏱️

검사 대기 LOT은 일정 시간이 지나면 **시스템이 자동으로 판정**합니다. 임시 저장해 둔 값이 전부 채워져 있으면 그 값으로, 아니면 시스템이 만든 값으로 판정합니다. 직접 입력해 보려면 제어 막대에서 시계를 **일시정지**하거나 배속을 낮추고 합니다.

</aside>

### B. 합격하면

- 코일 주문용 슬래브는 자동으로 열연 대기열에 들어갑니다.
- 주문 제품이 합격하면 영업 담당에게 "출하요청 가능" 알림이 갑니다.

### C. 불합격하면

1. LOT이 **보류** 상태가 되고, 걸려 있던 배정이 자동으로 풀립니다.
2. 수주에 연결된 LOT이면 시스템이 **재생산 1매**를 생산팀에 요청하고 영업 담당에게도 알립니다.
3. **불합격 관리**에서 LOT의 처리 상태를 보류 / 격하 / 폐기 중에서 고르고 **적용**을 누릅니다.

### D. LOT 추적

1. **LOT 추적**에 LOT 번호나 히트 번호를 넣고 **추적**을 누릅니다.
2. **역추적 ←**은 이 제품이 어떤 슬래브·히트·용선·원료에서 왔는지, **정추적 →**은 이 원료·히트가 어떤 제품·출하로 갔는지 보여 줍니다.

## 자주 생기는 문제

- **"모든 항목의 측정값을 입력해 주세요"**: 빈 항목이 있습니다. 표면 결함 칸도 채워야 합니다.
- **"이미 판정된 LOT이에요" / "검사 대기 LOT만 입력할 수 있어요"**: 시스템이 먼저 자동 판정했거나 다른 검사원이 끝냈습니다. 위 노란 상자를 참고합니다.
- **"불합격 LOT만 상태를 바꿀 수 있어요"**: 합격 LOT은 불합격 관리 대상이 아닙니다.
- **"검사 기준서 QS-…가 없어요" / "품목 기준정보가 없어요"**: 기준정보가 빠졌습니다. 관리자에게 요청합니다.
- **판정을 잘못 저장했다**: 되돌리는 기능은 없습니다. 연습 중이면 초기화를, 아니면 불합격 관리에서 상태와 메모로 정리합니다.
- **불합격률이 갑자기 오른다**: AI Agent가 "불합격률 상승"으로 감지해 팀장에게 알립니다. LOT 추적으로 같은 히트·강종을 확인합니다.
