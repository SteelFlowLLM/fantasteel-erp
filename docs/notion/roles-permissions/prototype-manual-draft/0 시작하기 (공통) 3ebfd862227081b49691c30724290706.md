# 0. 시작하기 (공통)

모든 역할이 먼저 읽는 페이지입니다.

## 1. 실행하고 접속하기

1. 터미널에서 프로젝트의 `app` 폴더로 이동합니다.
2. 처음 한 번만 `npm install`을 실행합니다. (Node.js 22.18 이상 필요)
3. `npm run dev`를 실행합니다.
4. 브라우저에서 `http://localhost:5173`을 엽니다.
5. 같은 와이파이의 다른 PC에서는 `http://<실행한 컴퓨터 IP>:5173`으로 접속합니다.

## 2. 홈 화면

- **시안 A / B / C 열기**: 같은 시스템을 세 가지 화면 구성으로 봅니다. 데이터는 하나라서 어느 시안에서 바꿔도 전부 같이 바뀝니다.
    - A: 왼쪽 사이드바 메뉴 + 오른쪽 AI 패널
    - B: 아이콘 레일 + 목록|상세
    - C: 상단 탭 메뉴 + 하단 AI 입력창
- **3안 나란히**: 세 시안을 한 화면에 띄우고, 창마다 역할을 골라 동시에 볼 수 있습니다.

## 3. 로그인

- 가장 쉬운 방법: 로그인 화면 오른쪽 **데모 계정**에서 역할을 누르면 비밀번호 없이 그 역할의 대시보드로 들어갑니다.
- 직접 입력: 사번 + 비밀번호 `heatline`
- 비밀번호를 5번 틀리면 계정이 잠깁니다. (관리자가 풀어 줍니다)

### 데모 계정

- 영업: 김영업 `2104012`
- 구매: 서구매 `1907015`
- 생산: 박생산 `1803021`
- 품질: 정품질 `1911030`
- 물류: 윤물류 `2005024`
- 팀장: 강팀장 `1502003`
- 관리자: 이관리 `1704010`
- 그 밖에 오영업 `2203027`, 최생산 `2006011`, 한품질 `2107019`도 쓸 수 있습니다.
- 문구매(비활성)와 남물류(잠김)는 처음부터 로그인이 안 되는 상태로 들어 있습니다. 관리자 기능 연습용입니다.

### 다른 사람으로 바꾸기

- 맨 위 검은 막대 오른쪽의 **사용자 전환**, 또는 화면 오른쪽 위 내 이름(로그아웃)을 누릅니다.
- 창이나 탭을 여러 개 열면 창마다 다른 사람으로 로그인할 수 있습니다.

## 4. 맨 위 검은 막대 (프로토타입 제어 막대)

디자인에는 없는, 시연용 도구입니다. **여기서 바꾼 것은 접속한 모든 사람에게 적용됩니다.**

- **A · B · C**: 지금 보는 화면을 다른 시안으로 전환
- **점(초록/빨강)**: 서버 실시간 연결 상태. 빨강이면 연결이 끊긴 것입니다.
- **시계**: 공장의 가상 시각. 처음 상태는 2026-10-02(금) 09:10입니다.
- **❚❚ / ▶**: 시계 일시정지 / 재생
- **1× 10× 30× 120× 600×**: 시간 배속. 기본 30×는 실제 1초에 공장 시간 30초가 흐릅니다.
- **+1h**: 공장 시간을 1시간 건너뜀
- **자동 조업**: 켜면, 담당자가 공장 시간으로 4시간(30×에서 실제 약 8분) 안에 처리하지 않은 일을 시스템이 대신 처리합니다. 히트 편성, 열연 배정, 출하요청·배정·출고, 발주, 입고, 신규 수주가 해당됩니다. **팀장 승인은 대신하지 않습니다.**
- **초기화**: 모든 데이터를 처음 상태로 되돌립니다.
- **AI**: AI 연결 상태와 설정

<aside>
⚠️

**직접 조작을 연습할 때는 자동 조업을 끄는 걸 권합니다.** 켜 두면 내가 하려던 일을 시스템이 먼저 해 버릴 수 있습니다. 또 **초기화**는 다른 사람이 하던 작업까지 모두 지우니, 같이 쓰는 중이면 먼저 알리고 누릅니다.

</aside>

## 5. 자동으로 흘러가는 것 (알고 있어야 덜 놀랍니다)

자동 조업을 꺼도 아래는 시간이 되면 시스템이 진행합니다.

- 계획된 히트의 제강 시작 → 연주 → 슬래브 LOT 생성
- 배정된 슬래브의 열연 압연 → 코일 LOT 생성
- **검사 대기 LOT의 자동 판정** (품질 담당이 제때 입력하지 않으면 시스템이 측정값을 만들어 합격/불합격을 냅니다)
- 매일 08:00 MRP 실행, 매시 정각 AI Agent 감지

브라우저 창이 하나도 열려 있지 않으면 공장 시계가 멈추고, 다시 열면 이어서 진행합니다.

## 6. 화면 공통 요소

- **메뉴**: 역할마다 다릅니다. 공통으로 LOT 추적, 작업 로그, 업무·알림, 메신저, 회의록이 있습니다.
- **검색창**: 수주번호(SO-…)는 수주 상세로, LOT·히트 번호는 LOT 추적으로, DR-…은 출하 배정으로, PR-…은 구매요청으로 이동합니다.
- **종 아이콘**: 알림(업무·알림 화면), **말풍선 아이콘**: 메신저
- **AI 어시스턴트**: 시안 A는 오른쪽 패널, C는 아래 입력창입니다. 조회만 하고 등록·변경은 하지 않습니다.
- 권한이 없는 메뉴로 들어가면 "권한 없음" 화면이 나옵니다.
