# HEATLINE 프로토타입 사용 설명서 (초안)

<aside>
✏️

**초안입니다.** 소스 코드(권한표·서버 로직·화면 코드)를 읽고 정리했고, 앱을 실제로 띄워 한 단계씩 눌러 보며 검증하지는 않았습니다. 버튼 위치나 문구가 화면과 다르면 화면이 맞습니다. 메뉴 이름은 **시안 A** 기준입니다.

</aside>

## 이 문서는

HEATLINE 프로토타입(제철소 업무 시스템, 45개 화면 × 시안 A·B·C)을 처음 만지는 사람이 **자기 역할 페이지 하나만 읽고** 따라 할 수 있게 만든 설명서입니다.

## 읽는 순서

1. **0. 시작하기**를 먼저 읽습니다. 실행, 로그인, 상단 제어 막대가 여기 있습니다.
2. 자기 **역할 페이지(1~7)**를 읽고 따라 합니다.
3. 막히면 **9. 문제 해결**에서 화면에 뜬 문구를 찾습니다.

## 전체 업무 흐름

한 건의 주문이 아래 순서로 흘러갑니다. 괄호 안은 담당 역할입니다.

1. **수주 등록** (영업) → 재고가 있으면 자동 예약, 모자라면 "생산 필요"로 생산에 넘어감
2. **생산계획·히트 편성** (생산) → 시뮬레이터가 제강 → 연주를 진행해 슬래브 LOT 생성
3. **검사** (품질) → 합격이면 다음 단계, 불합격이면 보류되고 재생산 요청
4. **열연 투입 배정** (생산, 코일 주문일 때) → 슬래브를 압연해 코일 LOT 생성 → 다시 검사
5. **출하요청·배정 확정** (영업) → **출고 확정** (물류) → 밀시트 자동 생성
6. 옆에서 도는 흐름: **MRP → 구매요청 → 승인(팀장) → 발주 → 입고** (구매)

## 역할 한눈에

- **영업**: 수주 등록·취소, 출하요청과 배정 확정
- **구매**: MRP 확인, 구매요청, 발주, 입고 확정
- **생산**: 히트 편성, 공정 실적, 열연 투입 배정
- **품질**: 검사 입력·판정, 불합격 LOT 처리
- **물류**: 출고 확정, 밀시트 조회·출력
- **부서장**: 구매요청 승인·반려, AI Agent 대응 후보 승인
- **관리자**: 사용자, 역할별 권한, 기준정보

## 용어 (최소한만)

- **LOT**: 추적 단위. 원료·용선·슬래브·코일마다 번호가 붙습니다.
- **히트(Heat)**: 전로에서 한 번에 녹여 만드는 쇳물 한 솥. 히트 하나에서 같은 규격 슬래브 여러 매가 나옵니다.
- **슬래브 / 코일**: 슬래브는 연주로 굳힌 판 모양 반제품, 코일은 슬래브를 열연으로 얇게 말아 놓은 제품. 슬래브 1매 → 코일 1개.
- **여재**: 주문에 연결되지 않고 남은 재고.
- **MRP**: 앞으로 7일 생산에 필요한 원료를 계산해 부족량을 알려 주는 기능.
- **밀시트**: 출고 제품의 성분·검사값 증명서.
- **FIFO**: 먼저 만든 것부터 먼저 쓰는 규칙. 배정 추천이 이 순서로 나옵니다.
