## 2. 기준정보 (MST)

| ID | 요구사항 | 상세 | 등급 |
| --- | --- | --- | --- |
| REQ-MST-001 | 품목 관리 | 원료, 슬래브, 코일 품목을 관리한다. 품목 단위 유형은 QTY(제품, 매수) / TON(원료, 톤). 품목 코드는 원료는 원료 코드(영문 3자 + 숫자 2자리, 예: ORE01), 슬래브·코일은 규격 코드(REQ-MST-003)를 쓴다. 원료는 원료 유형(철광석·석탄·석회석·합금철)을 지정한다 | P1 |
| REQ-MST-002 | 강종·성분 규격 관리 | 강종(초기 SS275, SM355A·SM355B·SM355C·SM355D, SPHC — KS D 3503·3515·3501 현행 명칭)과 강종별 적용 규격 번호를 관리한다. 강종별 성분 min/max는 제강 검사 기준으로 관리하고, 변경 시 새 버전을 만든다(REQ-QC-002). SM355는 A–D 등급을 각각 별도 강종으로 등록한다. SM355는 등급(A~D)별로 충격 시험 조건과 C·P·S 상한이 다르다. 히트 성분 판정은 등급별 기준을 쓰고, 등급이 다른 수주에는 쓰지 않는다. 수주는 등록된 규격(item)을 선택한다. 규격이 없는 등급(SM355C·D)은 규격을 먼저 추가해야 수주할 수 있다. 시연용 규격·수주 시드는 SM355A·SM355B만 만든다(시드 강종 4종 × 슬래브 규격 3종 = 슬래브 12·코일 12) | P1 |
| REQ-MST-003 | 제품 규격 관리 | 슬래브·코일 규격을 강종 × 두께 × 폭 × 길이로 고정한다. 규격별 1매 이론중량(두께(mm) × 폭(mm) × 길이(mm) × 7.85 ÷ 10^9, 톤)을 확정값(소수 3자리)으로 저장한다. 강종·두께·폭·길이 조합은 중복 등록할 수 없다. 수주·재고에 사용된 규격은 치수·이론중량을 수정할 수 없으며, 다른 치수가 필요하면 새 규격을 추가한다. 규격 코드는 유형(SL 슬래브 / CL 코일)-강종-두께x폭x길이로 만든다(예: SL-SS275-250x1500x10000) | P1 |
| REQ-MST-004 | 슬래브·코일 규격 매핑 | 슬래브 규격마다 대응 코일 규격 1개를 지정한다. 코일 이론중량은 코일 규격 치수로 계산하고(REQ-MST-003), 열연 계획 수율은 코일 1개 이론중량 ÷ 슬래브 1매 이론중량으로 계산한다. 매핑된 코일 이론중량은 슬래브 1매 이론중량을 넘을 수 없다 | P1 |
| REQ-MST-005 | 라우팅 관리 | 품목 유형(코일/슬래브)별 공정 순서와 공정별 계획 수율을 관리한다. 공정 변경은 데이터 수정만으로 반영한다. 열연 계획 수율은 입력하지 않고 규격 매핑에서 계산한다(REQ-MST-004) | P1 |
| REQ-MST-006 | 배합 원단위 관리 | 용선 1톤당 원료(철광석, 석탄, 석회석) 투입량(공통, 톤/톤)과 용강(히트) 1톤당 강종별 합금철 투입량(kg/톤)을 관리한다 | P1 |
| REQ-MST-007 | 고객사·공급업체 관리 | 고객사와 공급업체를 관리하고, 품목별 기본 공급업체 1곳을 지정한다 | P1 |
| REQ-MST-008 | 야드 관리 | 원료·슬래브·코일 야드를 관리한다. 야드 내 위치는 관리하지 않는다. 품목별 기본 야드 1곳을 지정하고, 입고·실적으로 LOT이 생성되면 기본 야드로 자동 지정한다 | P1 |
| REQ-MST-009 | 생산 설정값 관리 | 히트 용량(초기 250톤, 용강 기준), 납기 위험 기준일(초기 3일) 등 설정값을 변경할 수 있다 | P1 |

## 3. 영업·수주 (SO)

| ID | 요구사항 | 상세 | 등급 |
| --- | --- | --- | --- |
| REQ-SO-001 | 수주 등록 | 수주 1건에 코일·슬래브 품목을 혼합해 등록한다. 생산 경로는 수주 품목 단위로 라우팅에서 결정한다 | P1 |
| REQ-SO-002 | 수주 수량 | 수량은 매수(정수, 화면 단위는 슬래브 매·코일 개)로 입력한다. 톤은 매수 × 1매 이론중량으로 계산해 표시하며 저장하지 않는다 | P1 |
| REQ-SO-003 | 재고 우선 예약 | 수주 등록 시 합격·가용 재고를 먼저 예약하고(부분 예약 허용), 부족 매수만 생산계획으로 넘긴다. 코일·슬래브 모두 적용 | P1 |
| REQ-SO-004 | 수주 충족 현황 조회 | 수주 품목별 예약 / 생산중 / 검사합격 / 출하 매수와 진행률을 조회한다 | P1 |
| REQ-SO-005 | 부분 출하 상태 관리 | 수주 품목별 상태를 관리하고, 수주 헤더 상태(부분출하, 출하완료 등)는 품목 상태에서 계산한다 | P1 |
| REQ-SO-006 | 수주 취소 | 취소 시 예약을 해제하고, 생산 중 물량은 여재로 전환한다 | P1 |

## 4. 생산·MRP (PRD)

| ID | 요구사항 | 상세 | 등급 |
| --- | --- | --- | --- |
| REQ-PRD-001 | 생산계획 생성 | 수주 품목의 부족 매수로 생산계획을 생성하고 수주 품목과 연결한다 | P1 |
| REQ-PRD-002 | 히트 편성 | 수주 품목(강종) 기준으로 편성한다. 필요 용강량 = 부족 매수 × 1매 중량 ÷ 누적 계획수율(연주·열연), 히트 수 = ceil(필요 용강량 ÷ 히트 용량) | P1 |
| REQ-PRD-003 | 공정별 작업 실적 등록 | 제선(용선), 제강(히트), 연주(슬래브), 열연(코일) 실적을 등록한다. 작업 시작·완료를 기록한다 | P1 |
| REQ-PRD-004 | 열연 투입과 여재 | 필요 매수의 슬래브만 열연에 투입하고, 나머지 합격 슬래브는 미배정 여재로 남긴다 | P1 |
| REQ-PRD-005 | MRP 계산 | 수주 → 라우팅 수율 역산 → 필요 용선 → 원료·합금철 소요량을 계산하고 잔량·입고예정을 차감한다. 여재는 가용재고에 포함, 원료 안전재고 없음, 수주에 연결된 생산계획은 다른 수주의 입고예정에서 제외한다. 원료 수량은 톤(소수 3자리)으로 계산하고, 합금철은 용강(히트) 톤 × 원단위(kg/톤) ÷ 1,000으로 계산한다 | P1 |
| REQ-PRD-006 | 재생산 | 합격 매수가 수주 대비 부족하면 부족 매수만큼 재생산 계획을 생성한다. 자동 초안은 REQ-AGT-003 | P1 |
| REQ-PRD-007 | 실적 시뮬레이션 | 생산계획 기준으로 공정별 실적을 생성한다(시드·시연용, 화면에서 생산계획을 선택해 실행). 계획 수율은 고정하고, 0~5% 랜덤 손실을 연주 단계 슬래브 매수 감소로 반영한다. 열연 수율은 고정 | P1 |

## 5. 재고·예약·배정 (INV)

| ID | 요구사항 | 상세 | 등급 |
| --- | --- | --- | --- |
| REQ-INV-001 | 재고 관리 | 제품은 매수로 관리하고 톤은 매수 × 1매 이론중량으로 계산해 표시한다. 원료는 톤(소수)으로 관리한다. 제품 재고에는 예약 매수를 함께 관리한다 | P1 |
| REQ-INV-002 | 예약 | 예약은 매수 단위로 하며 상태는 ACTIVE / CONVERTED / RELEASED다. 예약과 배정은 분리한다 | P1 |
| REQ-INV-003 | 예약 대상(합격 재고) | 검사 합격 재고만 예약한다. 슬래브 = 히트 성분 합격 + 슬래브 검사 합격, 코일 = 상위 히트 성분 합격 + 코일 검사 합격 | P1 |
| REQ-INV-004 | 자동 예약 | 부족분 생산분이 검사에 합격하면 원래 수주 품목에 자동 예약한다 | P1 |
| REQ-INV-005 | 예약 해제 | 출고 확정 시 CONVERTED, 수주 취소 시 RELEASED로 해제한다. 만료는 없다 | P1 |
| REQ-INV-006 | 배정 | 출하요청·열연 투입 시 강종·규격이 일치하는 합격 LOT을 FIFO(출하 제품 생산완료일)로 추천하고 담당자가 확정한다. 배정 변경을 허용한다. 배정은 확정 시 생성하며 상태는 CONFIRMED / CONSUMED(출고 확정·열연 투입) / RELEASED(변경·취소)다. 추천은 저장하지 않고 작업 로그로만 남긴다. 배정 대기는 출하요청 품목의 미배정 상태다 | P1 |
| REQ-INV-007 | 불합격 LOT 제외 | 불합격 LOT과 불합격 히트의 하위 LOT은 예약·배정 대상에서 제외한다 | P1 |
| REQ-INV-008 | 여재 관리 | 미배정 합격 슬래브를 여재로 관리하고 가용재고에 포함한다 | P1 |
| REQ-INV-009 | 중복 예약·배정 방지 | 동시 요청 시 같은 재고가 중복 예약·배정되지 않아야 한다. 방식은 구현 단계에서 결정 | P1 |
| REQ-INV-010 | 정합성 보정 | 예약 매수 합계와 재고의 예약 매수를 주기적으로 비교·보정한다 | P2 |

## 7. LOT 추적 (LOT)

| ID | 요구사항 | 상세 | 등급 |
| --- | --- | --- | --- |
| REQ-LOT-001 | LOT 계층 | 원료 → 용선 → 히트 → 슬래브 → 코일을 LOT 관계로 연결한다. 합금철은 히트에 직접 연결한다(REQ-LOT-002) | P1 |
| REQ-LOT-002 | LOT 연결 규칙 | 원료 → 용선: 제선 실적 등록 시 원료별 투입량(용선량 × 원단위)을 입고일 순(FIFO)으로 원료 LOT에서 차감하고, 차감된 LOT만 기간 기반으로 연결한다(투입 기간 = 제선 실적 시작~종료). 용선 → 히트: N:M, 제강 실적 등록 시 용선 LOT을 생산 순(FIFO)으로 자동 투입한다. 히트 → 슬래브: 1:N, 슬래브 → 코일: 1:1. 합금철 → 히트: 제강 실적 등록 시 투입량(히트 톤 × 원단위 ÷ 1,000)을 입고일 순(FIFO)으로 원료 LOT에서 차감하고 실제 투입으로 연결한다 | P1 |
| REQ-LOT-003 | LOT 채번 | 원료 RM-원료코드-YYMMDD-NNN, 용선 HM-고로-YYMMDD-NN, 히트 HT-전로-YYMMDD-NNN, 슬래브 히트번호-SS, 코일 C + 슬래브번호(HT- 제외). 고로·전로는 코드로 식별한다(예: BF2, BOF1) | P1 |
| REQ-LOT-004 | 원료 LOT 잔량 | 원료 LOT별 잔량(톤)을 관리하고 투입 시 차감한다 | P1 |
| REQ-LOT-005 | 역추적·정추적 조회 | 코일에서 원료까지 역추적하고, 원료·히트에서 영향받는 슬래브·코일·출하를 정추적한다 | P1 |
