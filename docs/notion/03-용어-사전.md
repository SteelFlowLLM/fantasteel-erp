### 결정 사항

| 항목 | 결정 | 관련 용어 |
| --- | --- | --- |
| 원료 vs 원자재 | 원료로 통일 (요구사항 PRD-005·범위 제외, 기획안 제외 목록 수정 완료) | 원료 |
| 고객사 vs 거래처 | 고객사로 통일 (MST-007 수정 완료) | 고객사 |
| 부서 vs 팀 | 부서로 통일 (AGT-004 수정 완료) | 부서, 부서장 |
| 테이블명 단수/복수 | 단수로 통일. `lot_relation`, `business_event` (기획안 리스크 표 수정 완료) | LOT 관계, 작업 로그 |
| 컨벤션 예약 예시 | 요구사항 기준. 컨벤션 예시를 ACTIVE/CONVERTED/RELEASED, 모델 Reservation(수주 품목·제품 규격 기준)으로 수정 완료 | 예약, 예약 상태 |
| 배정 상태값 | 요구사항 INV-006에 정의: CONFIRMED / CONSUMED / RELEASED. 배정 대기는 출하요청 품목의 미배정 상태 | 배정 |
| 계정 테이블명 | employee로 통일 | 사원 |
| 합금철 단위 | 톤 기준. 합금철 원단위만 kg/톤으로 저장하고 MRP에서 ÷1,000 환산(PRD-005 반영). 수주는 매수 입력으로 결정(톤은 계산값, 사용된 규격은 수정 불가·새 규격 추가). 합금철 원단위는 용강(히트) 톤 기준 | 소요량, 배합 원단위 |
| HTML 표기 | 요구사항 기준. HTML을 Message → ERP, Voice2ERP, AI Factory Agent, 고객사로 수정 완료 | Message → ERP, Voice2ERP, AI Factory Agent |
| 제안 영문명 | 구매요청 Purchase Requisition, 입고예정 Scheduled Receipt, 배합 원단위 Specific Consumption, 불합격 상태 Disposition Status, 출고 확정 Goods Issue로 변경. 히트 편성·자동 판정·검사 항목·출하요청·재생산은 유지 | - |

| 용어 | PDF 정의 | 반영한 정의 (근거) |
