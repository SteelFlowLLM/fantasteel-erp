# 공통 코드 정의서

<aside>
📌

**이 문서의 역할**: 시스템에서 쓰는 코드 값과 한글 표시명을 정의한다. 여기서 정한 값이 `shared/src/codes/`에 그대로 옮겨진다. 코드를 작성하는 규칙(정의 위치, 검증 방식)은 코드 컨벤션 4장을 따른다.

**상태**: ✅ 확정 = 요구사항에 값이 정의됨 / 🟡 제안 = 요구사항에 분류만 있거나 없음, 팀 확정 필요

**변경 순서**: 이 문서 수정 → `shared/` 반영 → 필요하면 CHECK 제약 마이그레이션

</aside>

## 1. 작성 규칙

- 코드 그룹 ID와 값은 영문 대문자 의미어(UPPER_SNAKE)를 쓴다. 숫자 코드(`01`, `02`) 금지
- 요구사항에 정의된 값은 이 문서에서 바꾸지 않는다. 바꿔야 하면 요구사항 정의서를 먼저 수정한다
- 같은 단어라도 그룹이 다르면 별도로 정의한다 (예: 예약의 `RELEASED`와 배정의 `RELEASED`)
- 한글 표시명은 화면에 그대로 나가는 문구다. 용어 사전의 한글명과 맞춘다
- 코드 그룹 ID는 `shared/`의 상수 이름과 같다 (예: `RESERVATION_STATUS`)

### RESERVATION_STATUS · 예약 상태

근거: REQ-INV-002, REQ-INV-005

| 값 | 표시명 | 의미 |
| --- | --- | --- |

근거: REQ-INV-006

| 값 | 표시명 | 의미 |
| --- | --- | --- |
| CONFIRMED | 배정 확정 | 담당자가 LOT 배정을 확정함 |
